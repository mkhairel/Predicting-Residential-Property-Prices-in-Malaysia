# Predicting-Residential-Property-Prices-in-Malaysia
Predicting Residential Property Prices in Malaysia using data analysis and machine learning (Linear Regression), with interactive dashboard visualization.

## Overview
This project analyzes Malaysian residential property data to identify key factors influencing price and to build a predictive model using Linear Regression.

The analysis includes data cleaning, exploratory data analysis (EDA), statistical testing, and model evaluation. An interactive dashboard was also developed to visualize property trends across different states and property types.

The model uses features such as built-up area, number of bedrooms and bathrooms, property type, and location to predict property prices.

## Objective
- Identify key factors influencing property prices
- Perform statistical analysis
- Build predictive model

## 🛠 Tools
- Python (Pandas, Numpy)
- Seaborn
- Scikit-learn
- Matplotlib
- Google Colab

## Key Insights
- Location is the most important factor
- Property size strongly affects price
- Urban areas have significantly higher prices such as KL & Selangor
- Type property also plays a major role, where premium properties like bungalow are more expensive

## Model
- Linear Regression
- Evaluation metrics: R², MAE, RMSE

## Model Performance
- R² Score: 0.53
- RMSE: RM 762,974.61
- MAE: RM 435,124.30
- The model shows a good ability to predict property prices with reasonable accuracy.

Interactive dashboard built using Plotly in Google Colab.
